# Pi Coding Agent icon

`pi-coding-agent.svg` was retrieved from
[Dashboard Icons](https://dashboardicons.com/icons/pi-coding-agent), whose
native collection is distributed under Apache-2.0. Product names and marks
remain the property of their respective owners and are used here only to
identify the Pi integration.

action icon remains legible in both light and dark xlatch clients.
